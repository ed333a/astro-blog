## 你好 👋

我是一个喜欢折腾界面的开发者。白天写业务代码, 晚上研究「同一个功能怎么做才更好看一点」——
这个博客就是后者的产物: 一张背景图 + 一堆毛玻璃面板 + 一套能被配置驱动的主题参数。

## 这里会写什么

- **前端**: CSS 里那些容易被忽略的细节 (毛玻璃、布局、动效、主题切换);
- **Astro**: 内容集合、自定义 loader、静态生成的实践笔记;
- **设计与阅读**: 排版、配色, 以及读到的好书;
- **随笔**: 写作流程、工具折腾, 偶尔的碎碎念。

## 关于这个站点

| 项目 | 说明 |
| --- | --- |
| 框架 | Astro (静态生成) |
| 样式 | Tailwind CSS v4 (样式全部由工具类组成) |
| 视觉 | 背景图 + 毛玻璃面板, 日/夜两套配色 |
